# Frontend

Данная папка содержит реализацию клиентской части разрабатываемого продукта. Основным фреймворком
является React, а для локальной разработки и финальной сборки используется Vite. Для стилизации
используется TailwindCSS, а набор компонентов реализован [ui/shadcn](https://ui.shadcn.com).

### Начало работы

Для успешного и корректного запуска данной части продукта необходима запущенная серверная часть.
Подробнее о запуске данного модуля можно прочитать в соответствующем README-файле.

Шаг 0. Склонируйте репозиторий.
```bash
git clone https://github.com/Pelfox/edutrack.git
cd edutrack/frontend
```

Шаг 1. Установите зависимости. В проекте используется пакетный менеджер `pnpm`.
```bash
pnpm install
```

Шаг 2. Запустите локальный сервер Vite.
```bash
pnpm dev
```

### Сборка через Docker

Для каждой версии, прошедшей интеграционное тестирование и готовой к выпуску, создаются готовые
Docker-образы, рекомендуется использовать именно их для запуска в production-среде:
```bash
docker pull ghcr.io/pelfox/edutrack/frontend:latest
```

В случае необходимости локальной сборки, можно выполнить следующую команду:
```bash
docker build -f frontend/Dockerfile -t edutrack/frontend:latest frontend/
```
