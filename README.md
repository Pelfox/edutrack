# Трекер успеваемости студентов

Реализация курсового проекта, позволяющего учебным учреждениям отслеживать успеваемость и прогресс
студентов. Поддерживает базовое планирование расписания как для студентов, так и для преподавателей.

### Возможности

- Отслеживание успеваемости студентов;
- Поддержка загрузки заданий для дисциплин;
- Управление расписанием студентов и преподавателей;
- Разделение функционального интерфейса для разных уровней пользователей.

### Структура проекта

Для упрощения сопровождения и поддержки, проект разбит на две части:

* [Клиентская](./frontend) (frontend);
* [Серверная](./backend) (backend).

Для каждой из них публикуются соответствующие Docker-образы, позволяющие автоматизированно
разворачивать сервис даже после внесения изменений в исходный код. Помимо этого, для упрощения
тестирования и интеграции, развёрнуты GitHub Actions, автоматические собирающие образы под каждый
коммит.
